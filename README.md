# Escape_the_prison-Noemie_MAZEPA-CDOF1

## Escape the prison

### **Description**
This game is a text-based adventure game where the player must make strategic decisions to navigate through various scenarios, from escaping their cell to exploring vents, hallways, and secret tunnels. Each choice affects the outcome, with paths leading to freedom or failure. 

Can you outsmart the guards and escape?

#### Features

- Interactive text-based adventure game
- Multiple choices and outcomes
- Implemented using Python
- Graphical user interface using `tkinter`
- Easy to extend and modify

### **How to run the project**
#### Prerequisites

- Python 3.x
- `tkinter` (included with Python standard library)

#### Instructions

1. Clone the repository:

    ```sh
    git clone https://github.com/Noemiemz/Escape_the_prison-Noemie_MAZEPA-CDOF1.git
    cd Escape_the_prison-Noemie_MAZEPA-CDOF1
    ```

2. Run the game:

    ```sh
    python game_interface.py
    ```
